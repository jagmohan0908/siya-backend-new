# Indian review illustrations

Generated with the built-in imagegen tool. These are illustrations of fictional
people, not actual patients. The UI labels the existing review text as sample
content. The generated originals were inspected and then resized/re-encoded to
320px JPEG assets for app/network size; no patient identity was used.

Project assets:

- `assets/images/indian_review_man.jpg`
- `assets/images/indian_review_woman.jpg`

Male prompt:

> Use case: stylized-concept. Asset type: a single profile avatar illustration for an Indian Ayurveda mobile app sample review, not a real patient photo. Create one friendly Indian adult man age about 35, medium brown skin, natural black hair, simple light sage shirt, clean cream background, head and shoulders centered with generous space for circular crop. Refined soft editorial illustration, warm natural expression. Square image, no text, no logos, no watermark, no borders. Save as a project asset if the tool supports files.
